# bosai

地震・津波・緊急地震速報（EEW）・気象警報・台風・天気をまとめて表示する防災情報Webアプリです。データは A.A.S（Aegis Alert System）から取得し、ブラウザは同一オリジンのプロキシ（`/api/a2s/*`）経由でのみ A.A.S と通信します（アクセストークンはサーバー側の環境変数にのみ存在し、クライアントコードには含まれません）。

|---|---|
| バージョン | 1.0.0 |
| 状態 | 稼働中（再構築版への切替待ち） |

| 実装 | Next.js (App Router) + TypeScript |

## 機能

- **トップページ（ダッシュボード）**: EEWバナー（発表から10分間、登録地点の予測震度・到達予想・区域ポリゴン塗り分け地図）、津波バナー（沿岸線地図）、最新の地震（レポート画像＋震度マーカー地図、登録地点の実測震度）、登録地点の管理（地名検索／現在地、localStorage保存）、天気予報（Open-Meteo、気象庁モデル＋ECMWF）と雨雲レーダー（気象庁ナウキャスト、国土地理院タイル合成）、気象警報・注意報、台風情報、A.A.S接続状態
- **地震詳細**（`/quake?id=…`）: 震度レポート画像／マーカー地図、都道府県別最大震度、震度観測点一覧
- **地震一覧**（`/quakes`）: 過去72時間の地震（A.A.Sの保持期間）
- **マスターデータ参照**: 震度観測点（`/stations`）、津波観測点（`/tsunami-stations`）、火山（`/volcanoes`）、河川（`/rivers`、形状はライン数・座標点数に要約）、AMeDAS最新観測（`/amedas`、気象庁データを直接取得）
- **統計**（`/stats`）: P2P地震情報の履歴APIから過去7／30／90日の震度別・都道府県別・日別件数を集計（このページのみ A.A.S を経由しません）
- **PWA**: Service Worker（ナビゲーションはネットワーク優先、静的アセットはキャッシュ優先、API応答はキャッシュしません）

## データの流れ

ブラウザ → 同一オリジン `/api/a2s/*`（Route Handlers がサーバー側環境変数 `A2S_TOKEN` のトークンを付与）→ A.A.S 公開API。イベントは SSE（`/api/a2s/stream`、関数上限60秒＋再接続時のリプレイで復旧）と30秒ごとのREST回復取得で維持します。地図タイルは国土地理院、雨雲は気象庁ナウキャスト、天気は Open-Meteo からブラウザが直接取得します。

## 開発

```bash
npm ci
npm run dev    # 開発サーバー
npm test       # 単体テスト（Vitest、TZ=Asia/Tokyo）
npm run build  # 本番ビルド
```

環境変数（サーバー側のみ）:

| 変数 | 内容 |
|---|---|
| `A2S_TOKEN` | A.A.S 公開APIのクライアントトークン（`bosai-web`）。クライアントコード・リポジトリへの記載は禁止 |
